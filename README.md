

## A propos du projet

Le projet est développé avec **Laravel** mais n'utilise pas la même architecture.

Le code source est dans le dossier **src**

Dans ce dossier, il y'a 3 sous-dossiers: **App, Domaine & Support**

Le code du dossier **Domain**
est composé de classes telles que des modèles, des générateurs de requêtes, des événements de domaine, des règles de validation, etc.

Le code du dossier **Support** est composé de classes que l'on peut utiliser un peu partout

Le code du dossier **App** est composé de classes telles que les controlleurs, les resources, etc.
